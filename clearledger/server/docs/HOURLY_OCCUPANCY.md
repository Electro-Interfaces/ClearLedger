# Почасовая занятость ЭЗС

`GET /api/analytics/charge-sessions/hourly-occupancy`

Обязательные параметры: `company_id`, `date_from`, `date_to` (даты включительно).
Права проверяются через `assert_company_product(..., "sales")`, в каждом SQL
задан `company_id`; дополнительно применяется объектный scope участника.

Параметры представления:

- `tz=msk|local`, по умолчанию `msk`.
- `group_by=auto|station|connector`, по умолчанию `auto`. Одна станция в контуре
  выбирает физические коннекторы, несколько — станции. Явный `connector`
  поддерживает несколько станций.
- `connector_types` — CSV типов; `connector_ids` — JSON-массив строк физических ID.
  Условия складываются через И. Пустые CSV и JSON-массив не сужают выборку.
- `stations`, `regions` — CSV текущего контура. Номера станций разрешаются общим
  `station_locations_sql`: основной номер имеет приоритет перед прежним номером
  другой карточки; история после переименования сохраняется по `location_id`.
- `dim` и `dim_val` задаются вместе. Поддерживаются `station`, `region`, `connector`
  (тип), `user_type`, `client`, `charge_type`, `result`, `tariff`.

Идентичность станции — `charge_sessions.location_id`, проверенная на принадлежность
компании. Совпадение текста кодов не связывает сессию со станцией. Парк — текущие
`ev_charging`, без тестовых и `operational_status='decommissioned'`.
История состава парка по датам здесь не восстанавливается.

Физический ID — `station_id + ':' + trim(connector_no)`. Одинаковые типы на разных
портах не объединяются. Каталог `connectors` строится по паспорту станций и всей истории контура без
лимитов, независимо от собственного `connector_ids` и `connector_types`, поэтому
выбор можно расширить. Неиспользованные порты из паспорта также показываются.
`connector_type` каталога — тип паспорта либо последней известной сессии порта;
типовой отбор самих интервалов и стартов использует тип записи сессии. Если тип
порта менялся, он остаётся одним физическим портом и доступен по прежнему типу.

Ответ содержит согласованные `group_by`, `tz`, `period`, `hours`, `series`,
`connectors`, `quality`. Дополнительное поле `connector_types: string[]` — все
известные типы истории контура, включая строки без физического номера; собственные
портовые фильтры этот каталог также не сужают. Каждая серия содержит все 24 часа.

Занятые минуты — пересечение фактического полуоткрытого интервала
`[started_at, finished_at)` с периодом и часом. Учитываются начала до периода.
Перекрытия сначала объединяются внутри серии: станция занята, если занят хотя бы
один выбранный порт, без суммы и усреднения портов. Знаменатель каждого часа —
`60 × число календарных дней`, включая дни без сессий. Нулевые серии строятся по
станциям контура и известным из истории портам даже без записей выбранного периода.

Начатые сессии (`starts`) считаются отдельно по началу в периоде, даже если конец
неизвестен или некорректен. Энергия, оплата и исход по умолчанию не ограничивают
занятость; явный `dim` может сузить её. `duration_min` не используется как подмена
отсутствующего конца. Все вычисления и исходные интервалы остаются на сервере.

Времена сессий в БД — МСК без tz. `local` использует `regions.msk_offset` и для
часа, и для календарных границ периода; неизвестное смещение означает МСК.
`quality.last_session_at` — максимальное известное начало истории после фильтров,
со смещением `+03:00` независимо от режима отображения.

Показатели качества относятся к выбранному периоду и отборам:

- `missing_interval_sessions`: отсутствующее начало/конец, нулевая или отрицательная
  длительность; такие интервалы не занимают время. Строка без начала относится
  к периоду по известному концу; без обеих дат показывается в любом периоде,
  поскольку датировать её невозможно.
- `missing_connector_sessions`: пустой/пробельный номер. Валидный интервал
  участвует в станции, в том числе при известном типе и отборе этого типа;
  неизвестный физический порт не создаётся. В режиме коннекторов эта строка
  пропускается в сериях, но остаётся в quality. Фильтр физических ID её исключает.
- `unmapped_station_sessions`: отсутствующая либо чужая ссылка на станцию;
  сессия не получает серию. В суженном пространственном или объектном контуре
  такие записи не показываются: принадлежность выбранной станции неизвестна.
