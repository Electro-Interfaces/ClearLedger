# Документы в общей навигации

`/files` и контекстные `<product>/files` показывают общий каталог компании.
Каталог не хранит вторые экземпляры карточек: строки проецируются из своих
источников, а действия открывают существующие экраны с исходными ID.
Контракт серверной проекции описан в [SPACE_DOCUMENTS_PROJECTION.md](SPACE_DOCUMENTS_PROJECTION.md).

- `docId`: «Карточка» открывает `/docs?view=all&doc=<id>`, в том числе без файла.
- `fileId`: «Файл» отдельно вызывает авторизованное открытие вложения.
- `contractId` / `contractIds`: переходы в существующий реестр договоров;
  несколько связей не создают несколько карточек документа.
- `siteId`: экран площадки `/projects?...&project=<siteId>&ptab=docs`.
  `EzsProject.id` не заменяет `EzsSite.id`; `siteDocId` пока не адресует
  отдельную строку внутри экрана площадки.
- Прогон канала открывает `/connectors/<channelId>`.

Меню «Создать» открывает существующие формы документа (`/docs?view=all&new=1`),
договора (`<product>/contractors?sub=contracts&new=1`) и приёма файлов.
Создание идёт в общий реестр: папка не задаёт владельца и не передаёт уникальный
`subject_ref`. Закрытие и успешное сохранение снимают `new=1`.
Права и доступность изменения реквизитов определяет экран владельца и сервер.

Поиск показывает совпавшие документы из всех папок. `folder` и `q` в URL
проводника сохраняют место при возврате из карточки. «Назад»/«Вперёд» проходят
посещения, «Вверх» открывает родительскую папку. История разделена по компании;
встроенная RawPanel использует локальное состояние без изменения URL хозяина.

Обновление и повтор загрузки используют только источники активного профиля:
energy — документы пространства и прогоны каналов, office — документы учёта,
fuel — смены и поступления. Ошибка одного источника видна рядом с доступными
данными; загрузка, пустая папка и отсутствие совпадений различаются.

При проверке нужно монтировать и оболочку MainLayout/KeepAliveOutlet:
набор поиска по буквам должен сохранять фокус. Изолированная проверка
ExplorerView с мгновенным `fill` не обнаруживает перемонтирование по query.
Проверять также возврат из настоящих форм, мобильные нажатия, Enter,
контекстное меню, смену компании и отдельные закреплённые виды.
