# Настройка операторов связи

В разделе «Телефония → Настройки подключений» добавлена форма SIP-подключений
Mango Office, МегаФон, Билайн, МТС / Exolve и другого оператора. Параметры и секрет
сохраняются через API узла компании, без записи SIP-пароля в Ядро/Поддержку.

Сохранение создаёт черновик. Отдельное действие применяет параметры к Asterisk,
после чего экран проверяет реальную регистрацию. Основная линия выбирается
отдельно; активные звонки блокируют изменения действующей конфигурации.
Установочная линия отображается отдельно. Поддержаны регистрация и IP-авторизация,
UDP/TCP/TLS, отдельный Auth ID, SIP-домен, From user, прокси и адреса входящих серверов.

История API Mango/МегаФона открывает действующие коннекторы Поддержки. Для других
операторов наличие SIP-профиля не объявляет готовность их API-интеграции.
Журнал узла продолжает показывать все его звонки с начала вызова.

Черновик хранит revision начала правки. Фоновое обновление списка не позволяет
старой форме затереть новую версию. При смене компании форма размонтируется,
введённый пароль очищается. Стабильный key в VoiceLayout сохраняет его внутренний экран при смене раскладки.
Общая MainLayout пространства при переходе desktop/mobile пересоздаёт маршрут;
фактическая проверка выполнена отдельно в обоих режимах, сохранение незаписанной
формы через смену этой внешней оболочки не заявляется.

Контракт узла: Node Admin API 0.1.3-draft, `/api/v1/sip/operators`.
Пользовательский путь браузера: `/voice/api/v1/sip/operators`.
Подробности сервера/установки — `ContactHub/docs/sip-operators.md`.

Проверки: полный TypeScript подготовленного состава; браузерный сценарий
`e2e/megafon-voice.check.mjs` на вымышленных данных. Можно выполнить только новый
сценарий с `SIP_ONLY=1`: пять операторов, создание/применение/основная линия,
отказ при активном звонке, конфликт revision, смена компании, 390px и 1440px.
Browser plugin отсутствовал, использованы обычный Playwright и системный Chromium.

Функция выпущена в desk 1.2.818. Наличие коммита/образа не подтверждает включение
SIP-менеджера на конкретном узле; без него экран возвращает честный ответ о
необходимости настройки установки. Рабочие SIP-реквизиты не входят в примеры.
