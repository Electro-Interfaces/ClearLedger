## Два отказа и исправления

- `legacy_null_preserved`: тест вставлял 21-символьную невалидную дату в старое
  поле varchar(20). Исправлена только строка фикстуры и её точное ожидание:
  `legacy bad date` (15 символов). Дата остаётся не-ISO; миграция по-прежнему
  должна сохранять старое значение без догадок.
- `partner_bound_empty_objects`: тест ожидал одну legacy-строку при пустом
  доступе к объектам. Фактический ответ `200` —
  `{"items":[],"nextCursor":null,"total":0}`; 40 байтов и SHA-256 совпали с
  сохранённым наблюдением. Теперь тест строго требует пустые items и total=0.
  Ранний assert остановил два следующих запроса; teardown правильно выявил
  несоответствие числа вызовов. Это одна ошибка сценария и связанная ошибка
  контроля, а не третье падение бизнес-сценария.

строк. Независимая проверка исходников не нашла доказанного дефекта.

контейнеров и 124 временные БД. Перед каждым удалением БД клиентов/блокировок

посторонних ресурсов, исходники, index, HEAD и зависимости не изменились.

Pytest занял 1735,48 с, все стадии с очисткой — 1927,95 с. Эти значения относятся
