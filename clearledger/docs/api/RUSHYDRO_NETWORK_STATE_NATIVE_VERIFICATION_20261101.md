## Сохранённая первая совместная попытка

На `f0c922f3` прежние25 прошли, новые50 получили setup errors до business
call: импортированная session fixture имела другой pytest module namespace
и повторно вставляла фиксированные PK. Root изменил только test lifecycle:
одна реальная factory хранит один world/client для обоих модулей; исходный
owner выполняет закрытие. Новая PG использована для повтора. Ошибка первой
попытки сохранена отдельно; ни handler, ни policy/verifier ради неё не менялись.

## Границы

10000 candidates и5s — инженерный admission, не production capacity/SLA.

его полный runtime этим прогоном не проверен. Исторические проверки
create-options/POST не являются частью этих75.

сгенерированные17 не объявляются обновлёнными. Нет приёмки браузера,
ingress/SSO/CORS, партнёрского пилота, общего CI, договорных writers и всего
пространства. Рабочие флаги, merge и выпуск не выполнялись.
