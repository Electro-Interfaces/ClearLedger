## Сохранённая неуспешная попытка

Первый запуск на `832b64ce` прошёл native bootstrap, затем остановился на
`uq_ezs_unit_serial`: две станции одной компании получили одинаковый
синтетический serial. Это 25 setup errors и 0 исполненных бизнес-тестов.
Индекс и production-код не менялись; исправлены только serials скрытого
и чужого оборудования. Новый прогон использовал новую собственную БД.
Первая попытка сохранена отдельно и не переименована в PASS.

  общий CI и приёмку всего пространства. Merge, выпуск и рабочие флаги
