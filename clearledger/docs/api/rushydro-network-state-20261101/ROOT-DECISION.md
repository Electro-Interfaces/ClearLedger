# Root: минимальная реализация состояния сети

01.11.2026. Основание — TARGET на `9057088f`, интегрированный как `bf09e13e`.
Это выбранный инженерный контракт для следующей code Task; исполнения и
оценки производительности ещё нет.

D1/D2 сохранены: только разрешённый обслуживаемый парк выбранного региона,
scoped watermark, точный native mismatch, порядок точных objectId.
Финансы, raw metadata, native attention и производные состава/порядка исключены.

D3: начинаем с ограниченной операционной проекции у владельца
`services/network_state.py`, без вызова полного финансового отчёта.

- Продуктовый adapter передаёт авторизованный SQL selector объектов из
  существующих Query.conditions(objects), сохраняя company/object/org ceilings.
- Владелец получает не более 10001 авторизованной станции текущей сети:
  company + selector + существующее station_scope. При превышении 10000
  возвращается безопасный 503; частичная сеть не выдаётся за полный результат.
  Этот admission предшествует Python-фильтрам владельца/региона, поэтому
  относится к разрешённым кандидатам сети, не к окончательному E.
- Только нужные скалярные поля; не materialize ORM/metadata/сессии целиком.
  Обслуживание и регион определяют E существующими общими правилами.
  Нестроковый регион из metadata не превращается в публичное значение.
- До session MAX/positive-energy history в SQL передаётся именно E.
  История агрегируется до одной строки на объект; деньги, rhythm и dry
  для выбранных пяти полей не вычисляются. EMPTY не расширяется до ALL.
- `_возраст`, native mismatch и station_scope переиспользуются у владельца;
  при необходимости mismatch выделяется в один общий helper без изменения
  существующей native формулы. Adapter не содержит бизнес-формул.
- По ограниченной проекции E строится M (onlyProblems=mismatch). Сводка
  M полная до страницы. ID сортируются по UTF-8/C без нормализации.
  pageSize 1..200, default50; нет полного финансового отчёта с обрезкой.
- Новый подписанный cursor связывает версию операции, последний ID,
  dataThrough/effective point, filters/pageSize и текущий Query.binding
  principal/company/client/install/grant/scopes/object/org/policy.
  Текущие права проверяются на каждой странице. Изменение boundary/binding
  требует новой выдачи (400), отозванный доступ проверяется раньше.
  Сессии/паспорт могут изменяться; snapshot не обещается.
- Бизнес-чтение ограничивается 5 с и PostgreSQL statement_timeout 5 с
  в собственной транзакционной области запроса; безопасный 503 без SQL/params.
  Настройка не должна оставаться на возвращённом соединении пула.
  Пределы 10000/5с — инженерный admission, не измеренная ёмкость или SLA.

D4–D6: принимаются allowlist DTO и 12 частичных synthetic oracles TARGET
с описанными оговорками. asOf — ISO date 2000-01-01..текущая дата МСК;
сессии naive MSK, ответ с +03:00, паспорт/current status не исторический.
region — 1..200 символов, до20 непустых точных tokens через `|`;
onlyProblems — true/false; неизвестные query, непустое тело GET →422.
Текущий product Problem/headers и user/approved service с двумя scopes
сохраняются. Никаких новых прав/tenant override/рабочих флагов.

Приёмка кода требует реальных SQL/Authlib проверок выбранного нового пути,
пустого охвата, чужого tenant/org, скрытых будущих сессий, money invariance,
исторической даты и страниц/отзыва доступа. Пакет READ25 на `2da44d38`
принят отдельно; его результат не переносится на новую реализацию.
Экспорт Swagger/SDK и миграция потребителей следуют после проверки метода.
