# Проверка блокировок дел и видов документов

Приняты **84 PASS / 26 определений / 252 фазы** на исходниках `8a3921cf6c97501877cdc55a59cf60d6c64bdbf7`. Независимая проверка кода и результатов завершена: `ACCEPT_SOURCE_AND_RAW_WITH_LIMITS`. Изменения включены в ветку интеграции коммитом `0cc4628b`; результат отдельного прогона не объявляется проверкой всей объединённой ветки.

Регистрация документа, назначение дела и массовое назначение получают общую блокировку каталога перед блокировками карточек. Изменение видов, дел и дела по умолчанию, закрытие, перенос на следующий год и начальное заполнение справочника используют исключительную блокировку. Сохранён существующий ключ PostgreSQL; физические ключи нескольких компаний сортируются, совпадения удаляются. Блокировки удерживает транзакция вызывающего кода.

Проверены оба порядка ожидания реальными обработчиками и транзакциями PostgreSQL, закрытие дела одновременно с назначением по умолчанию, очистка назначения, отсутствие назначения при регистрации, массовая обработка с сортировкой карточек, перенос дел и сохранение срока хранения. Проверены ручной и автоматический номера, повторная регистрация, конфликты, права обычного пользователя, прежний порядок ошибок и откат счётчика. Идемпотентное получение договорных видов сохранило доступ обычного участника.

Начальное заполнение справочника сначала завершает прежний autoflush изменений ролей и пользователей, затем получает полный набор блокировок компаний. Новый вид при совпадении с закрытым делом получает пустое назначение; пустое назначение не заполняется закрытым делом. Существующее непустое назначение сохраняется, включая прежние несоответствия. Транзакция запуска приложения и остальные функции заполнения не менялись; полный запуск приложения не выполнялся.

Прогон использует полную native структуру: 341 модель и 347 таблиц, настоящие UUID/JSON codecs, ограничения и внешние ключи. До импорта приложения проверены отдельная тестовая БД, её владелец и обычная роль без административных прав. Все 84 пула тестовых соединений и общий пул освобождены на живом event loop; клиентов и блокировок в БД осталось 0/0. Два временных контейнера завершились штатно и удалены. Ограниченная проекция состояния 41 чужого контейнера не изменилась.

Проверка вызывает обработчики напрямую с программным актором, без HTTP/JWT. Отправка уведомлений перехвачена; реальная доставка не проверялась. Порядок аудита после commit сохранён. Полная регистрация с исходным барьером владения, повторная проверка после UPSERT счётчика, сохранение незаписанного ORM-состояния и последнее ожидание остаются отдельной работой. Также не приняты права получателей уведомлений, произвольные внешние писатели, глобальное отсутствие взаимных блокировок, весь раздел документов, общий CI, пилот и выпуск. Исходные M00–M19 и 11 сквозных требований сохранены; общего процента и релизного GO нет.
