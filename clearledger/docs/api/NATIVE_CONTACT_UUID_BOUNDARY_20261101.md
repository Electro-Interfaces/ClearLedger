# UUID компании контактного лица

SOURCE: дополнительная колонка CounterpartyContact.company_id использует
принятый result adapter CanonicalUUID из29baa0c6. Source8 читает её scalar
запросом до создания CompanyKey, поэтому значение драйвера должно пройти
ту же проверенную границу ORM, что и другие идентификаторы компании.

Физический UUID, nullable=False, CASCADE FK на companies.id, индекс и режим
as_uuid=True сохранены. Изменён один вызов типа; адаптер, драйвер, bind/literal,
ядро typed keys и правила доступа не меняются. Поля id/counterparty_id контакта
остаются прежними: новый путь не передаёт их в ключ с проверкой точного типа.

Legacy company контакта может отличаться от компании контрагента. Новый
родительский CompanyKey защищает реальную FK связь, не вводит запрет на
такой контакт и не требует membership в его исторической компании.

В Source8 уже есть определения реальной проверки успеха и ожидания компании
legacy контакта. Их исполнение на полной native схеме остаётся необходимым;
исправление не считается проверенным по прежним38/162 сценариям.
