# OpenAPI 405 и SDK: приёмка отдельного компонента · 01.11.2026

Приняты формальные ответы 405 для всех 17 операций и согласованные TypeScript wire types. Для `/contracts` обязателен `Allow: GET, POST`, для остальных путей — `Allow: GET`. Обработчики запросов, DTO, авторизация и правила доступа этой правкой не менялись.

Исходники: metadata `11ea93093e51d52a1ef0f86c636939c2e2060da3`, SDK `f196f8aa8113090540ca19bfc07a2dfb55a8b3d2`, исправленные тесты `13790dc626376fd2324aa23c80eeb1df9da2dd62` (peer repair `3cb1ede3f4c4f2125ae64902400f86ff2361d802`). После SDK менялись только два тестовых тела и пояснение документации; app/SDK сохранены побайтно.

Проверены и независимо сверены сохранённые результаты:

- 27 основных unittest и 177 подпроверок схемы/HTTP-профиля — PASS; 14 отдельных DPL-проверок, 42 setup/call/teardown отчёта — PASS. Все пять новых определений включены импортируемым discovery.
- Generate, freshness check, шесть официальных generator tests, export и компиляция шести consumers — PASS. Прежние пять примеров сохранены; шестой сохраняет десять прежних и добавляет четыре отрицательные проверки `Allow`.
- Снимок из 575 файлов совпадает с Git; 23 артефакта вывода/манифестов сверены по SHA-256. Schema SHA `61227d1bb7d3c4ab39ddef9a4b9cbc837a8a5f856a6cfed663697fe17518c5df` совпадает с generated provenance.

В каждом canonical/public представлении сохранён прежний oracle 14 nullable-контейнеров. Один новый полный пример create-options проверяется отдельно, включая обязательный `nextCursor: string | null`. Первые два падения старых ожиданий и ошибка отсутствующего pytest plugin до collection сохранены как история.

Это проверка отдельного компонента: прежние READ-тесты используют fake verifier/domain/ACL, новые 405/404-сценарии — падающие verifier/session guards. Реальные SQL/PG/OAuth и положительный POST этими тестами не проверяются. По 17 операциям отправлен DELETE; полный перебор неподдерживаемых методов не выполнен. SDK остаётся определениями типов.

Рецензент проверял исходники и сохранённый вывод, запусков не повторял. SDK manifest относится к parent11ea, новый consumer закреплён отдельно; отдельного argv-receipt TSC в SDK bundle нет. Root импортировал auth/config/database, но app.main и conftest не загружались. Единственная IPv6-проба urllib3 отклонена до bind; 33 строки stderr — предупреждения asyncio о времени задач, без ошибок тестов.

Общая M00–M19 программа и 11 общих требований остаются открытыми. Этот отчёт не принимает весь M09, окончательный CI, Swagger через рабочий ingress или выпуск. Точные хеши, состав результатов и ограничения: [JSON](PARTNER_OPENAPI_405_SDK_ROOT_VERIFICATION_20261101.json).
