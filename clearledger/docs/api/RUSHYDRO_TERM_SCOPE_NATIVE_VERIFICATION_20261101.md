Это первый reader-first этап. Он не добавляет площадки, запись новых условий, HTTP-методы, права или миграцию. Внутренний валидатор по-прежнему отклоняет `site`. Новые writers и их отдельная приёмка остаются впереди. Рабочие флаги, merge и выпуск не выполнялись.
