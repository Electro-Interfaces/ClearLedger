# report-kit — история

Semver: новая функция — minor, смена контракта строк (`head`/`rows`/`total`) или ключей
хранения — major.

## 1.3.0 — 17.10.2026

Плитка показателя `Tile` и ряд `TILE_ROW` — в наборе (были внутри «На сегодня»): над
таблицей только плитки, они же отборы. Второй экран на наборе — «Оборудование → Отчёты»:
пять отчётов, у каждого одна таблица, плитки выбирают, какая.

## 1.2.0 — 15.10.2026

Калькулятор: блок «Выделенное» — числа списком по порядку щелчков, действие (сумма по
умолчанию, разность, произведение, частное, среднее), формула и результат сразу;
нечисловые ячейки не берутся. Клавиша %, «100 + 5%» = 105, история вычислений,
копирование результата. Формулы: щелчок по заголовку числового столбца вставляет его
в формулу, пока открыт редактор. Проверка вычислений — `calc.test.ts` (node:test).

## 1.1.0 — 15.10.2026

Панель инструмента открывается в области дока слева от рельсы, рельса не сворачивается.
«Помощь» убрана из рельсы: помощь экрана — блок «Этот экран» в «Инфо». «Счёт» назван
«Калькулятор». Столбцы таблицы не растягиваются на всю ширину: свободное место уходит
в пустой столбец справа.

## 1.0.0 — 15.10.2026

Перенос отчётов КП СДО: таблица с меню столбца, Σ, закреплением, фильтрами, шириной и
порядком столбцов; карточка строки; рельса инструментов (калькулятор с выделением, свои
столбцы-формулы, поиск, столбцы, сравнение, отложенные цифры, помощь, «Обсудить»).
Исправлено против эталона: деньги в калькуляторе и выделении — два знака; сдвиг
закреплённых столбцов на долю пикселя (ширины по `getBoundingClientRect`).
Первый экран — «Эксплуатация → Мониторинг → На сегодня».
