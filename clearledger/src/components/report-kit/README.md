# report-kit — таблица с инструментами

Перенос отчётов КП СДО (`MPSNG/kp-sdo/lk-client`, 15.10.2026) в пространство. Версия —
`REPORT_KIT_VERSION` в `index.ts`, история — `CHANGELOG.md`. Первый экран на наборе —
«Эксплуатация → Мониторинг → На сегодня» (`workspace/OpsWorklistPanel.tsx`), второй —
«Эксплуатация → Оборудование → Отчёты» (`equipment/EquipmentReportsPanel.tsx`).
Третий — «Мониторинг → Производители» (`workspace/NetworkVendorsPanel.tsx`):
марки в основном списке, станции и модели в расшифровках, станционная сводная.
«Мониторинг → Надёжность» (`workspace/NetworkReliabilityPanel.tsx`): список станций,
раскрываемые региональные группы и сводная; дата среза в общей строке фильтров.
«Мониторинг → Состояние сети» (`workspace/NetworkStatePanel.tsx`): станции,
региональные группы и сводная; отметки для заявок, неизвестный статус работы не считается нулём.

## Что даёт

- **Таблица** `SheetTable`: залипающие шапка и итог, сортировка, меню столбца (сортировка,
  закрепить по столбец, скрыть, ширина по содержимому, полоски величины, фильтр по значениям
  или «от–до»), Σ у числовых столбцов, перетаскивание и ширина столбцов, страницы и «Строк на
  странице», стрелки ↑ ↓ ← →, Enter — карточка строки, тень у правого края.
- **Рельса**: кнопки встают в правую рельсу пространства (`RightDock`) под цветной чертой,
  пока экран с набором открыт: Калькулятор, Формулы, Поиск, Столбцы, Сравнить, Цифры
  («Обсудить» убрано решением МАГа 15.10.2026 — чат пространства и так в рельсе). Панель открывается в области слева от рельсы, как чат и «Инфо» (раздел дока
  `report`, слот `ReportSlot`); рельса при этом остаётся на месте. На ширине < 1024 те же
  кнопки — полосой `ToolStrip` над таблицей, панель — под ней.
- **Помощь экрана** — не отдельной кнопкой, а блоком «Этот экран» внутри «Инфо»
  (`useReportKit({ help })`). Элемент помощи создавать один раз (константой модуля):
  новый элемент на каждом рендере зациклит хранилище рельсы.
- **Плитки** `Tile` в ряду `TILE_ROW` — над таблицей только они; с `onClick` плитка — отбор
  или выбор таблицы отчёта (набор один на экран: у отчёта с несколькими таблицами плитки
  переключают таблицу, `key` у таблицы — чтобы настройки и фильтры не перешли на чужие столбцы).
- **Карточка строки** `RowCard`: окно по центру в две колонки — все поля строки (и скрытые) | отчёты-расшифровки
  её значений (`RelatedLink`) и блок «Действия»; листание по отфильтрованному порядку.
- **Расшифровка** `RelatedReport`: отчёт окном поверх карточки, закрыл — остался на той же строке. Переходов на
  другие экраны из карточки нет (канон МАГа 16.10.2026: пример — номер карты → все транзакции по карте).
- Внешнее хранилище из ref пишет только постоянная функция: inline ref в React 19 зацикливается (#185).

## Как подключить экран

```tsx
const kit = useReportKit({ id: 'my-report.v1', title: 'Мой отчёт', head, rows, total, hide, ready: !!data })

<ToolStrip onDiscuss={...} />
<SheetTable {...kit.table} caption="Мой отчёт" lines={['за октябрь']} onRow={(order, pos) => ...} />
<ToolPanel>
  <ReportTools {...kit.tools} searchHint="…" formulaExample="…" help={<Help />} compare={<Compare />} />
</ToolPanel>
```

`rows` — `(string | number)[][]`: число делает столбец числовым (выравнивание, Σ, полоски,
фильтр «от–до»). «₽» в подписи — деньги, всегда два знака. Дата строкой `дд.мм.гггг`
сортируется как дата. Пустая строка — бледный «—».

## Точки расширения

| Что | Как |
|---|---|
| Свой вид ячейки (ссылка, чипы) | `render(row, col)` — вернуть `ReactNode` или `undefined` для обычного показа. Данные для сортировки, фильтра и выгрузки остаются сырыми. |
| Начальная ширина | `defaultWidths: Record<number, number>` у `SheetTable`; ручная ширина пользователя имеет приоритет. |
| Таблица внутри расшифровки | `children` у `RelatedReport` заменяет простую таблицу при успешной загрузке непустого набора; состояния загрузки, ошибки и пустоты остаются общими. |
| Подсветка строки | `rowClass(row)` |
| Состав группы в таблице | `expand(row)` возвращает содержимое раскрытой строки либо `null`; `onRow` переключает раскрытие, `render` может добавить кнопку со стрелкой. Вложенные таблицы не переключают родительскую строку. |
| Флажки строк | `mark: { has, set, label }` — столбец флажков закреплён слева |
| Порядок строк наружу | `onView(order)` — для выгрузки и пачечных действий |
| Сводная по столбцу | `groupBy` + `onGroup` — значок в шапке |
| Выгрузка | `tableAttrs` — например `exportRows(...)` для `chargeExport` |
| Сравнение | слот `compare` у `ReportTools`: у каждого экрана своё «с чем сравнить» |
| Помощь экрана | `help` у `useReportKit` — показывается в «Инфо» |
| Статус в строке фильтров | `status` у `useReportKit` — необязательный узел справа от области учёта; создавать константой или через `useMemo`, как `help`. При уходе с экрана узел очищается. |
| Хранение | `STORAGE_PREFIX = 'report-kit.v1'`, ключи `:cols:<id>`, `:calc:<id>`. Смена смысла столбцов — новый `id` (`…v2`), иначе старые настройки лягут на чужие столбцы. |

## Токены

Пространство использует ту же лестницу поверхностей, что эталон.

| Эталон | Пространство |
|---|---|
| `di-surface-*`, `di-outline-variant`, `di-on-surface-variant` | те же |
| `blue-600` | `primary` |
| `gold` (поиск) | `amber-400` |
| `label-caps` 10 px капсом | `text-xs font-medium`, без капса (DESIGN.md: не меньше 12 px) |
| `num` | `tabular-nums` |
| `font-headline` | тот же (Manrope) |

## Отступления от эталона

- Сводная — своя у экрана (`workspace/ReportPivot`), набор её не заменяет: инструменты
  «таблицы» в виде «Сводная» выключены с пояснением; фильтры столбцов действуют на сводную.
- «Снимок» отдельной кнопкой не перенесён: снимок области уже есть в чате пространства
  (кнопка камеры в доке чата). «Обсудить» копирует описание экрана с отбором и открывает чат —
  беседу человек выбирает сам.
- PDF — снимок экрана общим `ExportButton`; Excel берёт видимые столбцы в порядке человека.
- Отложенные цифры живут до перезагрузки страницы.
