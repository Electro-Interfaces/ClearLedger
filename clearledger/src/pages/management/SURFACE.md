# Управляющее пространство, V1

Область: `/management`, сервис чтения, вход из штатного меню и переходы к оригиналам.
Режим Impeccable: Operate, scoped extension. Интервью и решение «делаем» приняты до Dispatch.
Существующие PRODUCT.md/DESIGN.md сохраняются; новая дизайн-система не вводится.

## Direction contract

THESIS: единый читаемый список доступной пользователю работы с явным указанием источника,
организации, давности и неполноты. Список сообщает только то, что вернул API.

OWN-WORLD: существующие semantic tokens, системный текст 14/12px, Manrope 18px в заголовке,
shadcn Tabs/Input/Select/Button/Badge, Lucide; светлая и тёмная темы проекта.

STORY: пользователь выбирает организацию, разрез и пространство, ищет нужное и переходит
к оригиналу. Ошибка одного источника не закрывает полученные записи.

FIRST VIEWPORT: заголовок, «Только просмотр» и обновление; ниже табы, фильтры, состояния
источников и строки. На телефоне формы складываются в колонку, мета остаётся под названием.

FORM: существующая композиция списка с фильтром; seed неприменим к согласованному scoped
extension. Календарь представляет agenda периода. В V1 API выдаёт здесь встречи;
UI не обещает наличие сроков задач в календаре. Поле due_at выводится только из ответа API.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Контракт и ограничения

- `/api/management/status`: auth и текущая компания; меню видимо только при `enabled=true`.
- `/api/management/overview`: `kind`, `space`, `query`, `limit=100`; календарь также
  `date_from`, `date_to`, `time_zone`. Все параметры, компания и actor входят в queryKey.
- Даты включительны в IANA-зоне браузера. API строит UTC-границы; UI показывает timestamps
  в той же зоне. Date-only срок остаётся календарным днём без сдвига.
- Query хранится только в памяти (`gcTime: 0`), без persistent content cache и demo fallback.
  Company-keyed remount очищает отбор до первого запроса новой организации.
- Ошибки источников выводятся по известным state; HTTP-тело и source.error не отображаются.
- Bridge проверяет `company` по membership `/me` до монтирования оригинала. Неизвестная
  организация блокирует переход. `chat` открывает штатную комнату; `task` — штатный TaskCard;
  `event` уже поддержан CalendarPage. Права на оригиналы проверяют существующие API.
- Новая поверхность только читает. Штатные оригиналы сохраняют свои существующие действия.
