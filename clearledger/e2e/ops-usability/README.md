# Проверки замечаний эксплуатации

Запуск из `clearledger` после установки зависимостей:

```bash
npm run test:ops-usability
```

Набор запускает собственный Vite на `127.0.0.1:3199` и Chromium. Авторизация,
рабочая БД и доступ к РусГидро не требуются. Настоящие компоненты отчётов и
HTTP-клиент работают с вымышленными ответами из `data.ts`; контексты компании
и периода заменены тестовыми. Для частного `PeriodControl` тестовый плагин
добавляет экспорт без изменения его кода. Production-сборка плагин не использует.

Проверяются:

- неизменность ширин на страницах с разными значениями, после сортировки и смены размера страницы;
- верхняя прокрутка, крайний правый столбец, обратная синхронизация, сохранение вертикальной позиции;
- ручная ширина и скрытие полосы, когда таблица помещается;
- календарь на четырёх настоящих отчётах: листание, выбор месяца/дня, отмена,
  отсутствие запросов до подтверждения и `as_of` после применения;
- отдельное региональное представление и работа фильтра региона над таблицей;
- ширины 1440, 1024 и 390, отсутствие переполнения страницы и ошибок браузера.

Системные полосы оставлены видимыми и в headless-режиме. Результаты и снимки
по умолчанию сохраняются в `/tmp/ops-usability-results`. Можно переопределить
`OPS_QA_OUTPUT` и `OPS_QA_CACHE`; для уже установленного совместимого Chromium
есть `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

Это проверка интерфейса с подменой API. Она не заменяет приёмку целевого
стека с обычной авторизацией и его рабочими данными.
