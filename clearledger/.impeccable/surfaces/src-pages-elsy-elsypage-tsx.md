# Элси+ в пространстве клиента

Режим: Operate. Действующий клиент продолжает работу с поставщиком и знакомится с другими продуктами из своего пространства. Приложение включается явно для выбранной компании; остальные пространства по умолчанию выключены.

THESIS: обращения, переданные документы и новые продукты доступны рядом с рабочими приложениями клиента. Нового коммерческого кабинета на сайте нет.

OWN-WORLD: наследуем существующий интерфейс Ledger, его светлую и тёмную темы, типографику, кнопки и боковую навигацию. Каталог состоит из читаемых строк с описанием задачи и состоянием доступа.

STORY: увидеть текущую работу, открыть продукт и учебный показ, передать вопрос команде с сохранением названия продукта.

FIRST VIEWPORT: общая оболочка пространства, шесть разделов слева; справа текущие обращения, кнопка «Написать нам» и знакомство с продуктами. На телефоне разделы в горизонтальной полосе.

FORM: расширение существующего рабочего приложения. Новая визуальная концепция и генерация вариантов не требуются; композиция следует принятой структуре из шести разделов.

Достоверность: каталог читается из общих сведений о продуктах через пространство поставщика. Готовые показы доступны сотруднику через права приложения и действующую связь компаний, на учебных данных. Учётная запись сайта для запуска не требуется. «Документы» показывают полученные вложения существующего моста, без отдельной базы договоров. Раздел «Мои сервисы» отражает состав и права текущей компании. Обращение использует общий мост и Поддержку.

Состояния: загрузка, отсутствие материалов, потеря связи, запрет доступа, ошибка отправки с сохранением черновика. Тестовые браузерные данные синтетические, в рабочую базу не записываются.
