## Вердикт по design specificity

Авторская здесь речь, а не композиция. «Дубли» — безусловно авторский экран (модель 008/208/ЦБ, эра продаж, легенда префиксов). «Цепочка» авторская на уровне модели данных: недоступный источник даёт прочерк, а не ноль. «Сверка» — шаблон: карточка + три KPI + таблица. Убери текст — три экрана неотличимы от любого дашборда, и в рельсе у них была одна иконка на троих.

## Когнитивная нагрузка

Провалено 7 пунктов из 8 в разрезе раздела (Chain 1, Parity 3, Dedup 7). Чистый на всех трёх — только прогрессивное раскрытие.

## Приоритетные проблемы

**[P0] Ошибка загрузки выдаётся за деловой факт.** При сбое запроса «Цепочка» показывала «снимка ещё нет», «Сверка» — «пар агент ↔ 1С пока нет». Экран, доказывающий готовность, при сетевом сбое доказывал обратное. → Исправлено: обе панели различают отказ центра и отсутствие данных, обе дают «Повторить».

**[P0] `armed` переживает подтверждение (Дубли).** Взвели «Перецеп боевой», свернули группу, вернулись через полчаса — один клик пишет в живую 1С. Не исправлено.

**[P1] Успех не имеет вида.** «Расхождений нет» выглядело пустым контейнером под заголовком «Что не сходится»; выполненный критерий кодировался только зелёным. → Исправлено на обоих экранах.

**[P1] Два «разобрано» на одном экране.** KPI считает по всему контуру, строка фильтров — по текущему отбору; при включённом фильтре «120 / 300» сверху и «разобрано 4» снизу. Не исправлено.

**[P1] Клавиатура и смысл в `title`.** Строка смены бралась только мышью; тревога — красный кружок без слова; кнопка загрузки дампа — иконка без имени. → Исправлено (rowDrill, sr-only, aria-label).

**[P2] Раздел собран тремя разными руками.** Разные отступы, три копии `когда()` (в «Сверке» без защиты от Invalid Date), молчаливый потолок 60 смен, выгрузки есть только у одного экрана. → Частично: дата и потолок исправлены, единый компонент шапки — нет.

## Персоны

**Alex:** перецеп по одной группе на ~300 групп, ни одного сочетания клавиш, отбор из 8 контролов не живёт в URL.
**Sam:** до правок — строка смены недоступна с клавиатуры, тревога только цветом, радио канона без имени; после правок остаются `title`-подсказки и `opacity-55` поверх `text-[9px]`.
**Riley:** пустые состояния трёх видов, из них один ложный; раскрытое расхождение рендерит все строки разом; длинные имена товара вытесняются одиннадцатью бейджами.

## Вопросы

1. Как выглядит раздел в день, когда 1С выключат? Ни один экран не показывает состояние «переход завершён», хотя оно и есть цель.
2. Кто нажимает «Перецеп боевой» — офис или станция? По группе не видно, кто уже принимал решение.
3. Три пункта — три жанра (момент времени, временной ряд, слои справочника). Различие было целиком в абзаце под заголовком.
