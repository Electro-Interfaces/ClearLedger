## 1. Категорийный менеджмент и ассортимент

**Ключевой факт (NACS):** в convenience-магазине **6 категорий** — упакованные напитки, сигареты, прочий табак (OTP), пиво, солёные снеки, конфеты — дают **~90% inside-продаж и прибыли** (без фудсервиса); три из них (напитки 34%, табак 28%, пиво 11%) = **73%** merchandise-продаж. → Фокус аналитики на малом наборе высокооборачиваемых/высокомаржинальных категорий, а не «всё подряд».

**Канонический классификатор — фундамент.** Стандартизированная таксономия (NACS Category Definitions, versioned — v8.0 от 2021, обновляется: Ready-to-Drink Coffee, Alcoholic Seltzer и т.д.) — *предпосылка* оптимизации ассортимента и бенчмаркинга. → У нас: категорийная иерархия должна быть **справочником, расширяемым во времени**, не хардкодом.

**8 шагов категорийного менеджмента:** (1) определить категории → (2) назначить **роли** → (3) оценить эффективность → (4) цели (margin/sales/volume) → (5) стратегии → (6) тактики (4 P's) → (7) внедрить → (8) пересмотр. Отслеживается **Category Scorecard**.

**Роли категорий** (destination / core / convenience / seasonal) определяют **ширину ассортимента**: destination — широкий выбор; routine/core — чёткие ценовые уровни + доступность; convenience — узкий набор высокооборачиваемых; image — защита бренд-образующих SKU.

**Локализация — через кластеризацию, не per-store.** «Дисциплинированная модульность»: национальное ядро → региональные модули → локальные варианты. Кластеризовать точки по паттернам спроса/ограничениям/миссиям покупателя; если два кластера получают одинаковый набор SKU — это не разные кластеры. → Для сети 5/8/208/209/210: кластеры станций, не уникальная матрица на каждую.

**Рационализация SKU:** сначала убрать **дубли**, потом резать покрытие (категория может нести много SKU и всё равно упускать нужные покупателю measures). **SKU action list**: keep/cut/add/expand/localize/test/exit + матрица распределения (где применяется по кластеру/сезону) + метрики (sales/margin/turns/availability/inventory). Аналитические приёмы: **Gap Analysis** (дыры ассортимента), **Hotspot Analysis** (топ/дно).

→ **В раздел «Магазин»:** под-экран «Ассортимент» = Category Scorecard (роль, sales/margin/volume, ABC-класс) + SKU action list + Gap/Hotspot. ABC — на наших данных; роли/матрица — редактируемые товароведом.

## 2. Ценообразование

**KVI (Key Value Items / товары-маркеры)** — драйверы трафика, формируют ценовое восприятие: цены на них держат конкурентными, зарабатывают на cross-sell высокомаржинальных. Практика: отслеживать **competitive price index на 30–50 KVI**, целевой коридор **0.98–1.02** (в пределах ±2% от конкурентов).

**3 ценовые роли ассортимента:** KVI (конкурентные, трафик) / **Volume Drivers** (маржа выше KVI, отбивают привлечение) / **Profit Drivers** (высокомаржинальные, низкий объём, необязательные).

**Ценовая эластичность зависит от категории:** staples −0.3…−0.6 (неэластичны), дискреционные −1.0…−2.0 (эластичны). → Изменения цен дифференцировать по роли категории.

**Локальное ценообразование по точкам даёт +3.46% валовой прибыли** против единой сетевой цены. → Мы уже видим цены по станциям — блок «разброс цены SKU по станциям».

**Промо — осторожно (BCG):** **20–50% промо не дают заметного прироста** (или минус), ещё **20–30% размывают маржу**. Оценивать по 3 параметрам: продажи (доля рынка), маржа (**ROI**), потребитель (трафик/лояльность). Структурированный промо-процесс поднимает маржу на промо на **2–5 п.п.**
- **Promo ROI = (Incremental Gross Profit − Promo Cost) / Promo Cost**; incremental = (Promoted Units − Baseline Units за тот же SKU/период) × Avg Price.
- Классифицировать эффект: **incremental lift** / **forward buying** (перенос будущего спроса) / **cannibalization** (за счёт sister-SKU). В исследовании ~140k промо: валовый рост +130%, но **~40% — каннибализация**. → Валовый lift переоценивает реальную ценность.
- Настоящий промо-P&L нетит: глубину скидки, финансирование поставщика, каннибализацию, halo, pantry-loading, рекламу, логистику, издержки магазина.

→ **В раздел «Магазин»:** под-экран «Цены и маржа» = маржа/наценка + разброс цен по станциям + (при данных) KVI-индекс и промо-ROI. Промо-модуль — nice (нужен промо-календарь + baseline).

## 3. Управление запасами и пополнением

**Оборачиваемость = COGS / Средний остаток.** Бенчмарки резко разнятся: розница ~11x, бакалея ~15x, **АЗС-магазины 24–37x/год**. Высокая оборачиваемость = сильные продажи + бережливый запас.

**GMROI = Валовая прибыль / Средний остаток по себестоимости.** > 1 — запас прибылен (продаём дороже, чем стоит запас); < 1 — теряем. Convenience-бенчмарк **$6.69** (2021, выше всех сравниваемых). Годовой средний остаток = (сумма начальных остатков Jan–Dec + конечный Dec) / 13. ⚠ «Здоровый GMROI» **оспаривается** — часто называют ~$2, но зависит от вертикали.

**Sell-through = (Продано / Получено) × 100** за период; near 100% — почти распродано (сигнал дозаказа), падение — приток обгоняет продажи (сигнал markdown/промо).

**Weeks of Supply = Текущий остаток / Средние недельные продажи** (historical vs forward WOS для прогнозного планирования). **Days Sales of Inventory = 365 / Оборачиваемость**.

**Lost Sales Ratio = (Дни OOS / 365) × 100** — упущенная выручка при отсутствии товара. **Взвешивать stockout по марже × сегменту** (дефицит высокомаржинального ходового товара бьёт сильнее). ⚠ Точность учётных остатков — слабое место рынка (только 42% брендов ≥80% точности) — у нас перекликается с проблемой минусов/расхождений остатков на 208.

→ **В раздел «Магазин»:** под-экран «Ассортимент/Запасы» = оборачиваемость + GMROI + sell-through + WOS + Lost Sales. Всё на наших данных (продажи + себестоимость + остатки; средний остаток — оценкой (нач+кон)/2).

## 4. Свежесть, сроки годности, потери

- **Shrinkage % = (Учётный остаток − Фактический) / Учётный × 100** — потери от воровства/порчи/пересчёта.
- **Spoilage / dead-stock share = (непродаваемый запас / доступный запас) × 100** — критично для скоропорта; рост = перезаказ → отвечают уценкой у истечения срока.
- **Markdown rate** — диагностический KPI: высокий (в одежде >8–10%) = перезакуп/переоценка; низкий (<3%) = консервативный закуп или сильный спрос.
- Свежее/скоропорт = дневной ML-прогноз + markdown-ценообразование у срока.

→ **В раздел «Магазин»:** shrinkage/spoilage — из инвентаризаций (book/fact/diff), markdown rate — из переоценок. FEFO/сроки годности — nice (нужны партии со сроками; у нас партии есть, срок — доп.поле).

## 5. Аналитика и KPI розницы

- **Average Transaction Value = Продажи / число транзакций** — средний чек (на ОРП-агрегатах — приближённо «позиций за смену», точно — нужен чек).
- **Basket value — на уровне копеек:** добавление 1 позиции может перевести чек из убытка в прибыль. Отслеживать **вместе**: число транзакций + средний чек + маржу чека (в 2025 транзакции −1.6%, чек +24¢, но маржа чека −8¢).
- **Sales per кв.м = чистые продажи / торговая площадь** — продуктивность площади (для АЗС с малым залом критично; нужна площадь).
- **Market Basket Analysis:** метрики **Support** (доля транзакций с A∪B), **Confidence** (P(B|A)), **Lift** (сила связи). Алгоритмы **Apriori** / **FP-Growth**. Применение: cross-sell, раскладка, управление запасами по со-покупкам. ⚠ Требует **чек-уровень**.
- **Attachment-эффект:** лотерея — маржа 5–6%, но **95% берут ещё что-то** (высокомаржинальное). Напитки/табак/пиво тянут бóльшие корзины.
- **Foot traffic / конверсия** — требует счётчик посетителей (за пределами ОРП).

→ **В раздел «Магазин»:** средний чек/структура — в MVP приближённо; market basket/cross-sell/конверсия — **главный next-step**, гейтится чек-уровнем.

## 6. Общепит / фудсервис

**Фудсервис — самая маржинальная зона c-store:** ~55% валовой маржи на prepared/roller-grill; **38.9% inside gross profit** при 28.5% продаж; **стал категорией №1** по продажам (обогнал напитки). → Приоритет для АЗС с кухней.

**Menu engineering — матрица popularity × profitability → 4 квадранта:**
- **Stars** (высокая маржа + популярность) — продвигать, в маркетинг;
- **Plowhorses** (популярны, низкая маржа) — корректировка порций, аккуратный рост цены, бандлинг с высокомаржинальным;
- **Puzzles** (высокая маржа, низкая популярность) — поднять видимость/описание/промо;
- **Dogs** (низкие оба) — переработать или вывести, освободить место.

Метрики:
- **Contribution margin = цена − стоимость ингредиентов** (+ переменные: труд на готовку, гарниры). **Profit margin % = CM / цена**.
- **Item popularity index = продано данного / всего продано блюд** (доля в миксе меню).
- Начинать с **food costing** (себестоимость блюда без труда). Пересчитывать матрицу **ежеквартально** или после изменений меню. **7–10 позиций на категорию** (против decision fatigue).

→ **В раздел «Магазин»:** под-экран «Общепит» (для станций с кухней) = menu engineering matrix + food cost % + contribution margin по блюдам. Полностью на наших данных (ТТК + продажи блюд + себестоимость ингредиентов FIFO).

## 7. Специфика convenience / магазина при АЗС

- **Магазин важнее колонки по прибыли:** merchandise + foodservice = **35% продаж, но 57.4% валовой прибыли** (vs топливо). → Оправдывает фокус аналитики на магазине.
- **Breakeven Pool Margin** — маржа топлива на галлон, нужная чтобы покрыть opex после вычета inside-прибыли; квантифицирует зависимость станции от топлива.
- **Конвертация «топливный клиент → покупатель в магазине» — решающий рычаг**; inside-транзакции падают (−3.0% в 2025). 28% заходят за конкретным, но уходят есть в другое место (пробел ассортимента/разнообразия).
- **Cold vault** (напитки + пиво) = ~25% продаж и прибыли; напитки — 80%+ прибыли cold vault. Приоритет для планограмм/ассортимента.
- **Высокомаржинальные импульсные:** конфеты >50%, солёные снеки ~40%, private-label напитки ~43%, авто-аксессуары/зарядки — наценка **+700%** к опту.
- **Сигареты — структурный спад** (единственная категория без роста в 2024), но остаётся топ-6. Учитывать в планировании ассортимента.

→ **В раздел «Магазин»:** «Обзор» = доля магазина в прибыли станции (магазин vs топливо), структура категорий, cold-vault/импульс. Привязка к топливу — уникальное преимущество (у нас есть и топливо, и магазин в одной платформе).

## 8. Современные технологии и тренды

- **ML-прогноз спроса ≥ традиционных** time-series (учитывает много драйверов сразу). **Погодные данные → −5–15% ошибки** на уровне товара, **до −40%** на уровне группы/магазина.
- Ручное промо-прогнозирование — слабое место (70% не учитывают все аспекты промо). ML должен моделировать **cross-product** эффекты (эластичность, каннибализацию).
- Скоропорт → **дневной** ML-прогноз для пополнения и снижения порчи.
- ⚠ Вендорские заявки об эффекте AI (продажи 2.3x, прибыль 2.5x, −65% упущенных продаж) — **маркетинговые, не независимые**; относиться скептически. Реальный измеримый эффект скромнее (см. погодный −5–40% ошибки как надёжный ориентир).

→ **Для нас:** ML — поздний этап. Сначала описательная аналитика (разделы 1–7) на исторических данных; прогноз/автозаказ — когда накопится история и появится lead-time поставщиков.

## Источники и надёжность

- **Первичные:** NACS `convenience.org` — State of the Industry / Category Definitions (структура категорий, доли, маржа фудсервиса, breakeven pool margin, basket-KPI); BCG — исследования промо/ценообразования (неэффективность промо, 3-параметрическая оценка, промо-P&L).
- **Вторичные/отраслевые:** метрики GMROI/оборачиваемости/sell-through/WOS, category management 8 шагов, menu engineering матрица.
- **Блоги/вендоры:** конкретные формулы и бенчмарки (проверять на своих данных); вендорские заявки об эффекте AI — с осторожностью.
- **Верификация:** adversarial-проверка корпуса — 64/75 фактов подтверждены (11 опровергнуто/спорны, в т.ч. отдельные бенчмарки GMROI помечены как contested).
